Title：Memoria Imaginum
A cloud-based photo management service for organizing and preserving memories.

1.Overview
Memoria Imaginum is a cloud-based photo management service that allows users to securely store, organize, and manage their photos.
The service is being developed as a full-stack web application using Angular, Spring Boot, and AWS.

2.Planned Features
・User authentication
・Photo upload and cloud storage
・Album management
・Photo search and filtering
・Photo sharing
・Storage usage management

3.STACK
Frontend

・TypeScript
・SCSS

Backend

・Java

Infrastructure
